## 📌 Project Overview
**Student Hub** is an easy-to-use web platform built to help students manage their daily studies in one single place. Instead of jumping between different apps, students can track their subject syllabus, calculate grades, monitor attendance, take digital lecture notes, and study core Computer Science subjects through organized roadmaps.

---

## ✨ Key Features
- **📚 Syllabus & Progress Tracker:** Check off completed topics across 13 core Computer Science subjects and watch your progress bar grow.
- **📝 Pravio Digital Notes:** Write clean notes, draw sketches on a canvas, create mind-map flowcharts, and study with flashcards.
- **⏱️ Study Utilities:** Built-in Pomodoro timer to stay focused, a daily task planner, and study streak counters.
- **📈 Attendance & GPA Tracker:** Monitor your attendance percentage and calculate your target GPA easily.
- **🔐 User Accounts & Security:** Secure sign-up and login system to save your individual progress and notes safely.
- **🌓 Light & Dark Theme:** Switch easily between light and dark modes according to your preference.

---

## 🛠️ Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (Clean, responsive, and mobile-friendly design)
- **Backend:** Python & Flask (Lightweight and fast web server)
- **Database:** SQLite (Stores user accounts and progress safely)
- **Deployment:** Render (Cloud hosting)

---

## ⚙️ How It Works
1. **Create an Account:** Sign up with your details to create your personal student profile.
2. **Track Your Courses:** Open any subject (like Python, DSA, Web Development, or SQL) and check off topics as you study them.
3. **Take Notes & Draw:** Use **Pravio Notes** during lectures to jot down points, sketch diagrams, or review flashcards.
4. **Monitor Your Goals:** Check your attendance calculator and study timer to stay on top of your semester goals.

## 🚀 Getting Started

Follow these simple steps to run this project locally on your computer:

### Prerequisites
Make sure you have installed:
- [Python 3.10 or higher](https://www.python.org/)
- Any modern web browser (Google Chrome, Microsoft Edge, Brave, Firefox)

### Installation
1. **Download or Clone the project:**
   ```bash
   git clone https://github.com/alpha9030/StudentHub-pr.git
   cd StudentHub-pr
   ```

2. **Install required packages:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application:**
   - On Windows, simply double-click `start_backend.bat`, or run:
     ```bash
     python app.py
     ```

4. **Open in browser:**
   Open your browser and visit:
   ```
   http://localhost:5000/
   ```
